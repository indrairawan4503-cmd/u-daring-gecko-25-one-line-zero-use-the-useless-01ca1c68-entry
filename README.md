# One Line, Zero Use — Variant C: The Microwave Millisecond

An entry for the make.fun bounty **"One Line, Zero Use: The Useless Superpower Sprint"**: one original line (194 characters) describing a hilariously useless superpower.

The power: stopping the microwave at the exact millisecond the popcorn pops — perfect, precise, and only usable mid-shower. The precision itself is the joke: every night it ends in a dripping-wet sprint back to burnt popcorn, a screaming smoke alarm, and a dinner eaten anyway.

## Run it

```bash
python3 main.py
```

This writes the entry line to `/output/entry.txt`. Deterministic: running it twice produces byte-identical output. Python standard library only, no network.
